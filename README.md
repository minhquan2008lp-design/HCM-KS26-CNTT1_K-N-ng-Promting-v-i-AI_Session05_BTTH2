# Prompt 1 – Nghiên cứu khách hàng

Bạn là chuyên gia nghiên cứu thị trường công nghệ.

Hãy nghiên cứu khách hàng mục tiêu của sản phẩm AI Chatbot dành cho doanh nghiệp.

Yêu cầu:
- Xác định 3 nhóm khách hàng mục tiêu.
- Phân tích nhu cầu và đặc điểm.
- Liệt kê ít nhất 5 Pain Points.
- Đề xuất cách AI Chatbot giải quyết từng vấn đề.

Đầu ra dưới dạng JSON gồm: target_audience, needs, pain_points, solutions, key_benefits.

Giọng văn chuyên nghiệp, khách quan. Không tự tạo số liệu.

#  Prompt 2 – Xây dựng dàn ý

Bạn là chuyên gia Content Marketing và SEO.

Dựa trên toàn bộ JSON từ Prompt 1:

[ DÁN OUTPUT PROMPT 1 ]

Hãy xây dựng Outline cho bài PR dài 1.000–1.500 từ.

Yêu cầu:
- Tạo tiêu đề Headline hấp dẫn.
- Viết định hướng đoạn Lead.
- Xây dựng các tiêu đề H2, H3.
- Phân bổ nội dung cho từng phần.
- Xác định từ khóa SEO chính và phụ.
- Xây dựng CTA cuối bài.

Đầu ra dạng JSON gồm: headline, lead, sections, keywords, CTA, word_count.

Không tự ý bỏ qua dữ liệu Prompt 1.

# Prompt 3 – Viết bài PR

Bạn là chuyên gia viết bài PR sản phẩm công nghệ.

Dựa trên dữ liệu Prompt 1 và Outline Prompt 2:

[ DÁN OUTPUT PROMPT 1 ]

[ DÁN OUTPUT PROMPT 2 ]

Hãy triển khai bài PR hoàn chỉnh dài 1.000–1.500 từ.

Yêu cầu:
- Có Headline và Lead hấp dẫn.
- Triển khai đầy đủ H2, H3.
- Phân tích Pain Points và giải pháp.
- Tối ưu từ khóa SEO tự nhiên.
- Có CTA rõ ràng ở cuối bài.

Giữ giọng văn chuyên nghiệp, tin cậy và nhất quán. Không tự ý thay đổi Outline hoặc bịa số liệu.
